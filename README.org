#+title: org-agenda-kanban-customized
#+author: Gregg Rothmeier (fork specific features: Stefan Caliandro)
#+options: toc:nil num:nil

A modern, mouse- and keyboard-driven *kanban board* for Org-mode TODOs.

Columns are TODO states; cards are your TODO headings, pulled live from a
configurable set of Org files.  The board is inspired by the visual polish of
[[https://github.com/minad/org-modern][org-modern]] and the tag-filtering UX of
[[https://github.com/skeeto/elfeed][elfeed]].

* Features

** New in this fork

#+begin_quote
*Disclaimer:* the features in this section were added in the fork
[[https://github.com/Caliandroid/org-agenda-kanban][Caliandroid/org-agenda-kanban]] and are
not part of the original package by Gregg Rothmeier.  They were created with
the assistance of [[https://claude.com/claude-code][Claude Code]], Anthropic's AI coding assistant.
#+end_quote

- *Add notes from the board (=z=).*  Press =z= (as in =org-agenda=) to run
  =org-add-note= on the selected card.  Type the note and press =C-c C-c=;
  it is timestamped and filed under the source heading — in its
  =:LOGBOOK:= drawer when ~org-log-into-drawer~ is set.  Afterwards (or
  after cancelling with =C-c C-k=) focus returns to the board.
- *Export to HTML (=e=).*  Press =e= (=M-x org-agenda-kanban-export-html=) to
  save the board as it is currently displayed — columns, sorting, and active
  filters — as one self-contained, responsive HTML file.  All CSS is embedded
  and nothing is loaded remotely, so the page works offline in any modern
  browser and can be mailed or shared as-is.  Priority and tag colors follow
  your Org configuration, due/overdue dates are highlighted, the page follows
  the reader's light/dark preference, and on narrow screens the columns stack
  vertically.  With =C-u e= the file is also opened in your browser.
- *Narrowed task view, e.g. for screen sharing.*  Press =N= to open the
  selected card narrowed to just that task: the source buffer shows only the
  card's subtree, fully expanded, so nothing else is on screen.  To make this
  the default for =RET=, =o= and double-click, set:
  #+begin_src emacs-lisp
  (setq org-agenda-kanban-visit-narrow t)
  #+end_src
  Widen again with =C-x n w=; the next visit from the board widens
  automatically.  Follow-mode previews are never narrowed.
- *Color cards by priority.*  Besides coloring the =[#X]= cookie, whole cards
  can be tinted by priority.  The color is blended into the card background,
  so text stays readable on light and dark themes; a selected card keeps the
  selection color.  Colors can be set just for the board (they take
  precedence over ~org-priority-faces~), and the HTML export uses the same
  tint:
  #+begin_src emacs-lisp
  (setq org-agenda-kanban-priority-style 'both      ; cookie | background | both | nil
        org-agenda-kanban-priority-colors '((?A . "#ff5555")
                                            (?B . "#ffb86c")
                                            (?C . "#f1fa8c"))
        org-agenda-kanban-priority-tint 0.25)     ; tint strength 0.0-1.0
  #+end_src
- *Done date from state-change notes.*  The done-date filter
  (~org-agenda-kanban-done-within-days~) no longer requires a =CLOSED=
  timestamp.  It also reads the notes Org writes when a done keyword logs its
  state change (e.g. =DONE(d@/!)=), such as
  =- State "DONE"       from "IN-PROGRESS" [2025-04-03 Thu 17:24]=, inside a
  =:LOGBOOK:= drawer or directly under the heading.  The most recent
  completion wins, so a reopened and re-finished task is dated by its last
  completion.  See [[*Recording when a TODO is marked done][Recording when a TODO is marked done]].
- *Show archived tasks (=v a= / =v A=).*  Like Org Agenda's archives mode,
  archived tasks are hidden by default and can be brought onto the board.
  =v a= shows TODOs in subtrees tagged =:ARCHIVE:=; =v A= additionally scans
  the archive files (e.g. =todo.org_archive=, see ~org-archive-location~) that
  =org-archive-subtree= moved tasks into.  Pressing either key again hides
  archives; so does clicking the =archives x= header chip.  To show them by
  default:
  #+begin_src emacs-lisp
  (setq org-agenda-kanban-show-archives t)   ; nil | trees | t
  #+end_src

** Original features

- *Columns from your workflow.*  Defaults to the keywords in
  ~org-todo-keywords~; fully configurable.
- *Live data.*  Cards are collected from files or directories in
  ~org-agenda-kanban-files~ (defaults to ~org-agenda-files~).
- *Click to select.*  Click a card to select it; the selection is shown with a
  distinct highlight.
- *Keyboard to move.*  Move the selected card between columns; the change is
  *written back* to the source Org file via ~org-todo~ (logging/notes honored).
- *Edit cards in place.*  Set the selected card's TODO state, priority, or tags
  with the usual Org menus (=s= / =,= / =:=); edits are written back to the
  source heading and the board refreshes.
- *Tags on cards, elfeed-style filtering.*  Tags appear as clickable chips that
  highlight on hover.  Left-click a tag on a card to *include* it (cards must
  carry every included tag); shift-click (=S-mouse-1=) to *exclude* it (cards
  carrying it are hidden).  A tag is only ever in one of the two filters.  Active
  filters appear as chips in the header line — =+#tag= for includes and =-#tag=
  for excludes — click one to remove it.  Tag chips honor Org's
  ~org-tag-faces~, so per-tag colors show through on the board; disable with
  ~org-agenda-kanban-use-tag-faces~.
- *Priority filtering.*  Filter by effective Org priority: unprioritized cards
  match ~org-default-priority~ (normally =[#B]=), just like sorting and
  =org-agenda=.
- *Priority coloring.*  The =[#X]= priority cookie on each card is colored
  using your configured ~org-priority-faces~ — the same source =org-agenda=
  uses (see ~org-agenda-kanban-priority-style~).
- *Planning timestamps.*  A card shows its =SCHEDULED= and =DEADLINE=
  timestamps when set, each on its own line beneath the title, with any
  repeater (e.g. =+1w=) preserved.  The redundant day-of-week name is
  dropped by default so timestamps fit the card width; keep it with
  ~org-agenda-kanban-planning-compact~.  Toggle the lines with
  ~org-agenda-kanban-show-planning~ and set the glyphs with
  ~org-agenda-kanban-scheduled-glyph~ / ~org-agenda-kanban-deadline-glyph~.
- *Due / overdue highlighting.*  When a card's =SCHEDULED= or =DEADLINE=
  moment is today or in the past, that line is recolored with a warning
  face, mirroring =org-agenda='s due/overdue colors, so slipping tasks
  stand out at a glance.  A timed entry (e.g. =09:00=) is "overdue" only
  once its time has passed; a date-only entry is "due" for the whole day.
  Repeating tasks are judged by their stored date, just like =org-agenda=.
  The colors come from Org's own faces — see [[*Priorities, tags, and faces (inherited from Org)][Priorities, tags, and faces]].
- *Schedule and set deadlines from the board.*  Press =C-c C-s= to set the
  selected card's =SCHEDULED= time and =C-c C-d= for its =DEADLINE=, the
  same keys =org-agenda= uses.  Both run Org's normal =org-schedule= /
  =org-deadline= prompts and write back to the source heading (=C-u=
  removes the timestamp).
- *Sorting.*  Within each column, cards are sorted by Org priority (highest
  first) by default.  Like ~org-agenda~, an unprioritized card is treated as
  ~org-default-priority~ (normally =[#B]=), so it interleaves with explicit
  =[#B]= cards.  Set ~org-agenda-kanban-sort~ to ~document~ for source order,
  or to a predicate for a custom order.

* Installation

This fork lives at [[https://github.com/Caliandroid/org-agenda-kanban][github.com/Caliandroid/org-agenda-kanban]].  The original
package is at [[https://github.com/greggroth/org-agenda-kanban][github.com/greggroth/org-agenda-kanban]]; to get the features listed
under [[*New in this fork][New in this fork]], install from the fork's URL as shown below.

** With ~use-package~ and ~:vc~ (Emacs 30+)

#+begin_src emacs-lisp
(use-package org-agenda-kanban
  :vc (:url "https://github.com/Caliandroid/org-agenda-kanban" :rev :newest)
  :commands (org-agenda-kanban)
  :custom
  ;; Optional fork settings, see "New in this fork".
  (org-agenda-kanban-visit-narrow t)
  (org-agenda-kanban-priority-style 'both))
#+end_src

** With ~package-vc-install~ (Emacs 29+)

#+begin_src emacs-lisp
(package-vc-install "https://github.com/Caliandroid/org-agenda-kanban")
#+end_src

** Manual clone (any supported Emacs, 28.1+)

#+begin_src sh
git clone https://github.com/Caliandroid/org-agenda-kanban.git ~/code/org-agenda-kanban
#+end_src

#+begin_src emacs-lisp
(add-to-list 'load-path "~/code/org-agenda-kanban")
(require 'org-agenda-kanban)
#+end_src

Or with ~use-package~:

#+begin_src emacs-lisp
(use-package org-agenda-kanban
  :load-path "~/code/org-agenda-kanban"
  :commands (org-agenda-kanban))
#+end_src

Update later with =git pull= in that directory.

** Switching from the original package to this fork

Both use the package name ~org-agenda-kanban~, and Emacs does not change the
source of an already installed package when you edit the URL in your config.
Remove the original first, otherwise it keeps being loaded:

1. =M-x package-delete RET org-agenda-kanban RET= (removes
   =~/.emacs.d/elpa/org-agenda-kanban=).
2. Point your configuration at the fork: change the ~:vc~ / ~package-vc-install~
   URL to =https://github.com/Caliandroid/org-agenda-kanban=, and check
   ~package-vc-selected-packages~ in your ~custom-set-variables~ — if it still
   lists =greggroth/org-agenda-kanban=, change that URL too (or remove the
   entry when you use a manual clone).
3. Restart Emacs; ~use-package~ / ~package-vc-install~ now installs the fork.

Check which copy is active with =M-x find-library RET org-agenda-kanban RET=:
the opened file should be from the fork (for a =package-vc= install, =git remote
-v= in its directory shows the Caliandroid URL).

If you prefer to keep an existing =package-vc= checkout, you can instead
re-point it and update in place:

#+begin_src sh
cd ~/.emacs.d/elpa/org-agenda-kanban
git remote set-url origin https://github.com/Caliandroid/org-agenda-kanban
git pull
#+end_src

then run =M-x package-vc-rebuild RET org-agenda-kanban RET= and restart Emacs.

* Org configuration

This package is deliberately a *view* over Org: it reuses the standard
=org-mode= and =org-agenda= settings you already have rather than inventing its
own.  No special setup is required to get started, but the board honors the
settings below, so customizing them in Org is reflected here too.

| Org / org-agenda setting              | What it drives on the board                               | Required?                  |
|---------------------------------------+-----------------------------------------------------------+----------------------------|
| ~org-todo-keywords~                     | Default columns                                           | No (used via ~columns~)      |
| ~org-agenda-files~                      | Default files scanned for cards                           | No (used via ~files~)        |
| ~org-log-done~ / =DONE(d!)= logging       | Writes the =CLOSED= line or state note the done filter reads | For the recently-done view |
| ~org-priority-faces~ / ~org-priority~     | Priority cookie colors                                    | No                         |
| ~org-default-priority~                  | Effective priority for unprioritized cards in sort/filter | No                         |
| ~org-tag-faces~                         | Tag chip colors                                           | No                         |
| ~org-scheduled~ / ~org-upcoming-deadline~ | =SCHEDULED= / =DEADLINE= line colors                          | No                         |

Moving a card runs ~org-todo~ on the source heading, so its TODO-state logging
and note prompts (e.g. ~org-log-into-drawer~, per-keyword logging) are honored
just as in a normal Org buffer.

** Recording when a TODO is marked done

The done-date filter (~org-agenda-kanban-done-within-days~) keeps
recently-completed cards on the board and hides older ones.  A done heading's
close date is the most recent of

- its =CLOSED= timestamp, and
- its state-change notes into its current done keyword, such as
  =- State "DONE"       from "IN-PROGRESS" [2025-04-03 Thu 17:24]=, whether
  inside a =:LOGBOOK:= drawer or directly under the heading.  Notes of child
  headings are ignored, and matching ignores case.

Org only writes these when you ask it to, either globally or per keyword:

#+begin_src emacs-lisp
(setq org-log-done 'time)   ; CLOSED line; or 'note to also prompt for a note
;; or log the state change itself, e.g. with a timestamp (!) or note (@):
(setq org-todo-keywords '((sequence "TODO" "|" "DONE(d@/!)" "CANCELLED(c@/!)")))
#+end_src

A task that was reopened and finished again is dated by its last completion.
Done headings with neither a =CLOSED= line nor a matching note are always shown
(their age is unknown), so the day-window filter can't hide them.

** Priorities, tags, and faces (inherited from Org)

The board pulls its colors straight from Org, so whatever you already customize
shows up here:

- *Priority colors* reuse ~org-priority-faces~ (falling back to the
  ~org-priority~ face), the same source =org-agenda= uses.
  ~org-default-priority~ (normally =[#B]=) controls where unprioritized cards
  land in the default priority sort and which priority filter they match.
- *Tag colors* reuse ~org-tag-faces~ on every tag chip; turn this off with
  ~org-agenda-kanban-use-tag-faces~.
- *Planning colors* reuse Org's planning faces: ~org-agenda-kanban-scheduled~
  inherits ~org-scheduled~ and ~org-agenda-kanban-deadline~ inherits
  ~org-upcoming-deadline~, so timestamps track your theme like the rest of the
  board.  When a planning moment is due today or overdue the line switches to a
  warning face that likewise inherits Org's own due/overdue faces:
  ~org-agenda-kanban-scheduled-today~ (~org-scheduled-today~) and
  ~org-agenda-kanban-scheduled-past~ (~org-scheduled-previously~) for scheduled
  cards, and ~org-agenda-kanban-deadline-today~ (~org-imminent-deadline~) and
  ~org-agenda-kanban-deadline-overdue~ (~org-warning~) for deadlines.  Restyle
  any of these faces to taste, or make them match the base face to turn the
  highlighting off.

* Usage

Run =M-x org-agenda-kanban= to open the board.

A ready-made sample board lives at [[file:examples/demo.org][examples/demo.org]] — open it and follow
the comment header (it sets ~org-agenda-kanban-files~ and
~org-agenda-kanban-columns~ to that file) to see every feature at once: all
five columns, priorities, tag chips, =SCHEDULED= / =DEADLINE= lines with
repeaters, inline markup, and recently-closed cards.

** Keybindings

| Key                  | Action                                      |
|----------------------+---------------------------------------------|
| =mouse-1= (card)       | Select card                                 |
| =mouse-1= (card tag)   | Toggle that tag in the *include* filter       |
| =S-mouse-1= (card tag) | Toggle that tag in the *exclude* filter       |
| =mouse-1= (header tag) | Remove that tag from the filter             |
| =n= / =p=                | Select next / previous card in column       |
| =f= / =b=                | Move selection to next / previous column    |
| =F=                    | Toggle follow-mode source preview           |
| =TAB= / =S-TAB=          | Move selection forward / backward column    |
| =M-<right>= / =>=        | Move card to next column                    |
| =M-<left>=  / =<=        | Move card to previous column                |
| =t=                    | Set the selected card's TODO state          |
| =,=                    | Set the selected card's priority            |
| =+= / =-=                | Raise / lower the selected card's priority  |
| =:=                    | Set the selected card's tags                |
| =C-c C-s=              | Set the selected card's =SCHEDULED= time      |
| =C-c C-d=              | Set the selected card's =DEADLINE=            |
| =z=                    | Add a timestamped note to the selected card |
| =s=                    | Save all Org buffers                        |
| =e=                    | Export the board to a single HTML file      |
| =k= / =c=                | Run =org-capture=                             |
| =RET= / =o=              | Visit card's heading in its Org file        |
| =double-mouse-1=       | Visit card's heading in its Org file        |
| =N=                    | Visit card narrowed to just that task       |
| =\=                    | Toggle a tag in the *include* filter (prompt) |
| =/ t= / =/ +=            | Toggle a tag in the *include* filter (prompt) |
| =/ -=                  | Toggle a tag in the *exclude* filter (prompt) |
| =/ r=                  | Remove a tag from the filter (prompt)       |
| =/ p=                  | Filter by effective priority (prompt)       |
| =/ c=                  | Clear all filters                           |
| =/ d=                  | Set the done-card date window (prompt)      |
| =v a=                  | Toggle archived (=:ARCHIVE:=) subtrees        |
| =v A=                  | Toggle archived subtrees and archive files  |
| =g= / =r=                | Refresh                                     |
| =q=                    | Quit                                        |

With a prefix argument (=C-u RET= / =C-u o=), the card's heading opens in
another window instead of the current one.

To show nothing but the task — handy when sharing your screen — press =N=:
the source buffer is narrowed to the card's subtree and fully expanded.  Set
~org-agenda-kanban-visit-narrow~ to ~t~ to make =RET=, =o= and double-click
always do this.  Widen again with =C-x n w=; the next visit from the board
widens automatically.  Follow-mode previews are never narrowed.

Follow-mode (=F=) mirrors Org Agenda: when enabled, changing the selected card
automatically previews its source Org heading in another window while keeping
focus on the kanban board.  As in Org Agenda, the heading's line is highlighted
in the source buffer so the matching outline item is easy to spot, and the
highlight follows the selection as you navigate.

Board edits use Org's normal commands and leave the source Org buffer unsaved,
matching Org Agenda.  Press =s= (=org-save-all-org-buffers=) when ready, just as
in Org Agenda.

* Customization

See =M-x customize-group RET org-agenda-kanban RET=.  Key variables:

- ~org-agenda-kanban-files~ — files or directories to scan (default
  ~org-agenda-files~).
- ~org-agenda-kanban-columns~ — column keywords (default from
  ~org-todo-keywords~).
- ~org-agenda-kanban-sort~ — order of cards within each column.  ~priority~
  (default) sorts highest Org priority first; like ~org-agenda~, an
  unprioritized card is treated as ~org-default-priority~ (normally =[#B]=) and
  interleaves with explicit =[#B]= cards.  Equal priorities keep document
  order.  ~document~ keeps source order.  May also be a predicate of two cards
  (passed to ~sort~).
- ~org-agenda-kanban-column-width~ — fixed column width in characters.  Must be
  at least 3 so the selection bar still leaves room for card content.
- ~org-agenda-kanban-column-gap~ — blank columns between board columns
  (default 2, must be non-negative).
- ~org-agenda-kanban-buffer-name~ — name of the board buffer (default
  ~*Kanban*~).
- ~org-agenda-kanban-render-markup~ — render Org inline markup in card
  titles (default ~t~).  Emphasis (=*bold*=, =/italic/=, =~code~=, …) is
  shown with its face and markers hidden, and links =[[target][desc]]= are
  shown as their description.  Set to ~nil~ to display raw Org text.
- ~org-agenda-kanban-done-within-days~ — only show done cards closed within
  this many days (default 7; ~nil~ shows all).  The close date is the
  =CLOSED= timestamp or the latest =- State "DONE" …= note, whichever is newer.
  Done cards with neither are always shown, and active (non-done) cards are
  always shown regardless of this setting.  See [[*Recording when a TODO is marked done][Recording when a TODO is marked
  done]] for how to record the close date.  Adjust live with =/ d=, or click the
  =done <=Nd x= header chip to show all done cards.
- ~org-agenda-kanban-show-archives~ — whether archived tasks appear on the
  board, mirroring ~org-agenda-archives-mode~ (default ~nil~).  ~nil~ hides
  them: subtrees tagged =:ARCHIVE:= are skipped while
  ~org-agenda-skip-archived-trees~ is non-nil (its default), as in
  =org-agenda=.  ~trees~ shows TODOs inside archived subtrees; ~t~ also scans
  the archive files used by the configured files (per
  ~org-archive-location~).  Toggle live with =v a= / =v A=; an =archives= or
  =archives+files= header chip shows the current mode.
- ~org-agenda-kanban-priority-style~ — how a card reflects its Org priority
  (default ~cookie~).  Colors come from ~org-agenda-kanban-priority-colors~
  when set, otherwise from Org's own ~org-priority-faces~ (with the
  ~org-priority~ face as fallback), the same source =org-agenda= uses, so
  priorities look consistent across Org.  Choices: ~cookie~ (color the =[#X]=
  cookie — the default), ~background~ (tint the whole card), ~both~, or ~nil~
  (no priority coloring).  Only cards with an explicit priority cookie are
  tinted, and a selected card keeps the selection background.  The HTML
  export applies the same tint.
- ~org-agenda-kanban-priority-colors~ — alist of =(PRIORITY . COLOR)=, e.g.
  ~'((?A . "#ff5555") (?B . "orange"))~, used for the cookie and the card
  tint in preference to ~org-priority-faces~ (default ~nil~).
- ~org-agenda-kanban-priority-tint~ — how strongly the priority color is
  blended into the card background, from ~0.0~ to ~1.0~ (default ~0.25~).
  The blend keeps text readable on both light and dark themes.
- ~org-agenda-kanban-show-planning~ — show each card's =SCHEDULED= and
  =DEADLINE= timestamps when set (default ~t~).  Each is rendered on its own
  line beneath the title with any repeater preserved.  Set to ~nil~ to hide
  them.
- ~org-agenda-kanban-use-tag-faces~ — color tag chips using Org's
  ~org-tag-faces~ (default ~t~).  Each tag's color is layered onto the chip
  while the package's state decoration is preserved (included tags stay
  inverse, excluded tags keep their strike-through), and a fixed-pitch family
  is forced so a per-tag face cannot break the card grid.  Set to ~nil~ to use
  the package faces only.
- ~org-agenda-kanban-header-remove-glyph~ /
  ~org-agenda-kanban-header-done-window-prefix~ — text used in header filter
  chips for the remove marker (default ="x"=) and done-window comparison
  prefix (default ="<="=).  These default to ASCII for portable fixed-pitch
  rendering; set them to Unicode values such as ="✕"= / ="≤"= if your font
  supports them with matching metrics.
- ~org-agenda-kanban-scheduled-glyph~ / ~org-agenda-kanban-deadline-glyph~ —
  prefixes shown before the scheduled (default ="S "=) and deadline (default
  ="D "=) timestamps.  These default to ASCII labels so their width is
  deterministic: cards are a fixed-pitch monospace grid, and a non-ASCII glyph
  that is absent from your fixed-pitch font is drawn from a fallback font whose
  advance does not align to the grid (misaligning the timestamp).  You may set
  a Unicode glyph (e.g. ="◷ "= / ="⚑ "=) only if it is present in your
  fixed-pitch font with matching metrics.
- ~org-agenda-kanban-planning-compact~ — when non-nil (the default), omit the
  day-of-week name from planning timestamps (e.g. =2026-06-03 11:00 +1w=
  instead of =2026-06-03 Wed 11:00 +1w=) so they fit the card width.  Set to
  ~nil~ to keep the weekday name.
- ~org-agenda-kanban-visit-narrow~ — when non-nil, visiting a card
  (=RET=, =o=, double-click) narrows its source buffer to that task's subtree
  (default ~nil~).  =N= always narrows, whatever this is set to.
- ~org-agenda-kanban-html-export-file~ — default file name offered by
  =org-agenda-kanban-export-html= (default ="kanban.html"=, relative to the
  board buffer's directory).
- ~org-agenda-kanban-html-title~ — heading and =<title>= of the HTML export
  (default ="Kanban"=).
- ~org-agenda-kanban-line-spacing~ — buffer-local ~line-spacing~ for the board
  (default ~0~).  Cards are solid colored tiles; if your frame or theme adds
  inter-line spacing, the card background does not fill it and faint stripes
  appear between a card's wrapped lines.  ~0~ removes that space so tiles read
  as continuous.  (Note: ~nil~ inherits the frame's spacing — the usual cause
  of the stripes — so prefer ~0~.)
